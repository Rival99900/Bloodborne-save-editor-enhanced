- Confirmation/status keyboard focus stays within the modal; Escape closes it and closing restores the previous focus where possible.

## Initial feature suggestions (before the reconstruction below)

1. Save presets: a test character, chosen stat values, consumable quantities, and validated Gem/Rune presets, with a preview and one-step Undo. Do not present numeric stat edits as permanent invincibility.
2. Change comparison: show named fields/items before and after rather than only raw bytes; mark unknown fields clearly.
3. Build library: export/import character equipment plans and indicate which items are missing. Reuse the experimental confirmation for equipment creation.
4. Compatibility assistant: record the user-confirmed CUSA and game revision, backup status, and in-game test results without guessing a title ID from unverified bytes.
5. A separate optional cheat-file companion: read and validate supported GoldHEN JSON metadata, show title/version/process and export a reviewed file. Do not inject executable cheat patches into save bytes or auto-apply arbitrary offsets.

GoldHEN's documented cheat files target a game process (commonly `eboot.bin`) and are selected for a title ID and version. This is distinct from editing serialized save values. See the [official repository](https://github.com/GoldHEN/GoldHEN_Cheat_Repository). Persistent health/stamina freezing, game speed, or similar runtime effects would require separately researched, version-specific runtime support; no such functionality has been implemented here.
